# gosling v1.2.2

This version was built and installed locally on macOS on 2026-09-08.

:::info Publication status corrected 2026-09-08
This note originally said no tag or GitHub release was published by this
change. `v1.2.2` was in fact tagged and published as a GitHub release later
the same day (`2026-09-08T15:57:08Z`, targeting commit `f5a910578`). See
[the published release](https://github.com/cephalopod-ai/gosling/releases/tag/v1.2.2).
[v1.2.4](v1.2.4.md) is the current published release.
:::

The Outputs pane now has a **Hide repository files** switch. It hides recognized
source-code/project files and files in Git, Mercurial, or Subversion directories,
including Git worktrees. The switch is off initially, remembers its setting, and
updates the visible count with a separate hidden count. It works alongside the
existing file-extension preference and preserves open previews and stored metadata.

Files whose repository membership cannot be checked remain visible with an
explanatory status. Standalone data and documents remain visible unless their
filename identifies a project file.

See [Workspaces and Outputs](../guides/workspaces.md#filter-repository-files) for
usage, and the [Goose comparison](../guides/goose-comparison.md) for the dated
source comparison with Goose v1.49.0.

Validation and installation evidence is recorded in the repository's
`docs/logs/session/2026-09-08-outputs-repository-filter.md`.
