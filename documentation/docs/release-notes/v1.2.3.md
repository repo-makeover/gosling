# gosling v1.2.3

This is the current source/local-build version. It collects the changes completed after the
v1.2.2 local installation and was built and installed on macOS on 2026-09-08. The installed
Copy contents action was verified on a Library document. No tag or public GitHub release is
created by this update.

- **Copy contents:** a separate preview-toolbar button beside Copy path copies complete UTF-8
  text, including Markdown, even if the preview is truncated. Files are limited to 20 MiB;
  binary documents remain available through Save a copy or Open externally.
- **Output history:** records the contributing agent, provider, selected/resolved model when
  known, originating chat, and saved revisions. History supports text comparison, exact-byte
  export, and confirmed restore as a new revision. Markdown products receive a history footer.
  Earlier authors remain unknown; read-only references do not claim authorship.
- **File timestamps:** Outputs and Library rows show filesystem creation and modification times
  in the local timezone.
- **Workspace readiness:** workspace rows indicate when a chat has new ready activity.
- **Visible dialogs:** confirmation dialogs appear above the Outputs pane and fit the viewport.
- **Temporary scratch files:** ordinary temporary writes no longer require workspace approval
  in Autonomous mode when working-directory restriction is off. Other folder rules still apply.

See [Workspaces and Outputs](../guides/workspaces.md) for behavior and limits. The
[Goose comparison](../guides/goose-comparison.md) retains its dated Goose v1.49.0 source baseline
and identifies this local version separately from public releases.

Validation was limited to affected tests, type/lint checks, and builds. The full suite was not
rerun. Output snapshots are local, bounded, path-based history, not Git commits or a continuous
external-file watcher; they survive chat deletion and output Trash actions.

Build and installation evidence is recorded in
`docs/logs/session/2026-09-08-v1.2.3-local-install.md`.
